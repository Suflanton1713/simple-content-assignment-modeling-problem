# Modelos no usados en la bateria principal

Estos modelos se conservan como referencia historica, pero no forman parte de las corridas principales actuales.

## Movidos aqui

- `simple_content_assignment_enhanced.mzn`: variante base con calculo de diferencias por pares.
- `simple_content_assignment_enhanced_engagement.mzn`: variante con engagement.
- `simple_content_assignment_epsilon_consensus.mzn`: epsilon no dirigido original, reemplazado en pruebas por `simple_content_assignment_epsilon_consensus_free_optimized.mzn` y variantes `*_chuffed_*`.
- `simple_content_assignment_epsilon_consensus_directed.mzn`: epsilon dirigido original, reemplazado en pruebas por `simple_content_assignment_epsilon_consensus_directed_optimized.mzn` y variantes `*_chuffed_*`.
- `simple_content_assignment_epsilon_consensus_free_reducing_conntent.mzn`: variante lexicografica de reduccion de contenidos; no se usa en la bateria principal actual.
